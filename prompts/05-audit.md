# Audit the Build

New session — the session that built it will defend it.

```
Read brief/brief.md and plans/00-general.md. Then audit this codebase and the running app against every requirement in the brief.

For each requirement:
- Score it 0–100% implemented
- Point to where it lives (file or screen)
- Say what's missing or broken

Also find: screens that can't be reached, flows that break, empty/loading/error states that are missing, and anything that looks bad on mobile.

Finish with an overall percentage and a ranked fix list, weighted by the rubric. Don't fix anything yet.
```
