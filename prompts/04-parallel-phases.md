# Run Phases in Parallel

Once the blocking phase is merged, run independent phases at the same time — one session (or worktree) each.

```
We're building phase [##] only. Other phases are being built in parallel in separate branches, so don't touch files outside this phase's scope: [list folders/features].

Read brief/brief.md, plans/00-general.md, plans/phase-[##]-[name].md, and AGENTS.md. Build the phase, then walk its part of the demo path.
```
