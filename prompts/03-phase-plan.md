# Phase Plan + Build

New session per phase.

```
Read brief/brief.md, plans/00-general.md, and AGENTS.md (then only the rules/ files this phase needs).

Write plans/phase-[##]-[name].md from plans/phase-template.md for phase [##]: a short checklist that covers only this phase's requirements.

Then build it. Use subagents for independent parts. When done, run the app, walk the demo path for this phase, and tell me what you clicked and what you saw.
```

When it works: skim the diff, then ask it to commit and open a PR. Start a new session for the next phase.
